The share sheet

Share it, and it is on the shelf.

One habit in every app you read in: tap share, choose Shelf, and the link arrives with its text and a summary. Nothing to paste, nothing to file.

01

Tap share, then Shelf.

The sheet lists Shelf first. One tap and the link leaves the app you were reading in.

02

Shelf reads the source.

The post text with what it quotes, a video’s title and description, or the title and description a page publishes.

03

It lands with a summary.

The save is on the shelf before you switch apps, with the source attached and a summary to skim.

For agents

A research note is a save too.

An agent files what it found with one request. It gets a ref back, shares the shelf’s search, and its HTML artifacts open in a sandboxed page — the same list a person reads.

Pricing

One plan, while it is early.

Every workspace is on Cloud Pro. The managed AI key is included, so a summary arrives without you pasting a key anywhere. Checkout opens later; nothing to cancel today.

The self-hosted Worker is open source and free, if you would rather run it on your own Cloudflare account.
